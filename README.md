# PYTHON-LAB-PROGRMAS
# Python Programs – SAMS and Data Analysis

## 📌 About

This repository contains simple Python programs developed for learning **Python programming, SAMS (Smart Academic Management System) concepts, data validation, student management, and basic data analysis**.

## 🛠️ Technologies Used

* Python 3
* Pandas
* Matplotlib
* Seaborn
* Basic Python Data Structures

## 📂 Programs Included

### 1. Environment Check

Checks the Python version, operating system, and development environment for SAMS.
The program also displays a SAMS welcome message.

### 2. Student Registration

Accepts student details such as:

* Name
* Roll Number
* Age
* CGPA
* Semester Fee

It also validates age and CGPA before creating the student record.

### 3. Grade Calculation

Calculates grades based on marks and generates the semester GPA.

Grade points are assigned from **O, A+, A, B+, B, C and F**.

### 4. Data Validation

Validates:

* Roll number
* Email
* Phone number

It also cleans and formats student records.

### 5. Student Repository

Stores student records, course information, student enrollment, and faculty-course mapping using Python data structures.

### 6. Eligibility Checking

Checks whether a student is eligible for:

* Promotion
* Scholarship
* Academic probation

The decision is based on CGPA, attendance, and family income.

### 7. Attendance Management

Calculates subject-wise attendance percentage and displays a shortage alert when attendance is below 75%.

### 8. Dictionary Programs

Demonstrates Python dictionaries and accessing values using keys.

### 9. Filter Function

Demonstrates the Python `filter()` function to find even numbers from a range.

### 10. Pandas DataFrame

Creates a DataFrame containing student information such as name and age.

### 11. Student Performance Data Analysis

Uses Pandas, Matplotlib, and Seaborn to analyze student performance.

It includes:

* Dataset creation
* DataFrame creation
* Dataset shape
* Column names
* Data types
* Missing values
* Mean
* Median
* Standard deviation
* Scatter plots
* Histogram
* Boxplot

## ▶️ How to Run

### Step 1: Install Python

Download and install Python from the official Python website.

### Step 2: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 3: Open the Project

```bash
cd YOUR_PROJECT_FOLDER
```

### Step 4: Run a Python Program

```bash
python lab1.py
```

You can replace `lab1.py` with any other Python file.

### Step 5: Install Required Libraries

For data analysis programs:

```bash
pip install pandas matplotlib seaborn
```
